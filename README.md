# Work Files

## Financial Services Risk and Product Analytics

[Explore the portfolio](financial-risk-analytics-portfolio/README.md)

Three synthetic analytics projects covering claims operations, risk-review performance, and a filing experiment. Includes sample datasets, Python analysis, SQL and SAS adaptations, Tableau build instructions, and an offline dashboard.

Download or clone this repository, then open `financial-risk-analytics-portfolio/dashboard/index.html` in your browser.

All portfolio data is synthetic. See the project documentation for validation status and limitations.

### Open the interactive dashboard
GitHub's file viewer cannot preview this 3.5 MB HTML file and does not run dashboard HTML.

1. On the repository home page, choose **Code → Download ZIP**.
2. Extract the ZIP on your computer.
3. Open `financial-risk-analytics-portfolio/dashboard/index.html` with Chrome, Edge, Firefox, or Safari.

The dashboard is self-contained; Python and Tableau are not required to view it. On a phone, a file preview may not run JavaScript; a computer browser is the simplest way to use the filters.
