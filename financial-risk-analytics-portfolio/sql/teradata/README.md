# Teradata adaptation
Run `schema.sql` in your chosen database, then import the three curated CSVs using your approved Teradata client. Map header order to column order; skip headers and map empty values to SQL NULL. `MULTISET` tables preserve rows so uniqueness tests can expose duplicates. Verify 6,000 claims, 1,800 alerts, and 8,000 assigned users, then execute `metrics.sql`. This adaptation is not tested against a live Teradata system. String dates use ISO format; durations are precomputed integers to keep definitions identical across engines. For production, prefer typed dates, documented time zones, ingestion reconciliation, and access controls.
