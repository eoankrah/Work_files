# Dataset dictionary

All records are synthetic, generated by seed 20261003. No protected or identifying customer data.

## claims
Grain: one row per claim

| Field | Type |
|---|---|
| claim_id | VARCHAR(16) |
| carrier | VARCHAR(30) |
| claim_type | VARCHAR(20) |
| channel | VARCHAR(20) |
| opened_date | VARCHAR(10) |
| cohort_month | VARCHAR(7) |
| closed_date | VARCHAR(10) |
| status | VARCHAR(10) |
| missing_documents | INTEGER |
| first_response_hours | DECIMAL(12,2) |
| cycle_days | INTEGER |
| age_days | INTEGER |
| paid_amount | DECIMAL(14,2) |
| sla_days | INTEGER |

## alerts
Grain: one row per alert (many alerts may reference a claim)

| Field | Type |
|---|---|
| alert_id | VARCHAR(16) |
| claim_id | VARCHAR(16) |
| rule | VARCHAR(30) |
| risk_score | DECIMAL(6,4) |
| reviewed | INTEGER |
| confirmed_issue | INTEGER |
| review_hours | DECIMAL(12,2) |
| days_in_queue | INTEGER |

## filing_experiment
Grain: one row per unique assigned user

| Field | Type |
|---|---|
| user_id | VARCHAR(16) |
| assigned_date | VARCHAR(10) |
| variant | VARCHAR(12) |
| channel | VARCHAR(20) |
| completed_7d | INTEGER |
| rework_7d | INTEGER |
| support_contact_7d | INTEGER |

Blank closed_date/cycle_days denotes an open claim; blank confirmed_issue/review_hours denotes an unreviewed alert. Reviewed confirmation is an investigation outcome, not a legal determination. Paid_amount is cumulative settled amount for closed claims; zero for open claims. The raw feed adds 12 duplicate rows, 8 missing carriers, and 5 negative amounts. Curated data is generated independently as the trusted fixture; no remediation lineage is implied.
